# Structured Authoring with DITA

This sample demonstrates topic-based technical documentation
using DITA XML.

The content is separated according to user intent:

- Concept: explains what automated processing is.
- Task: explains how to configure it.
- Reference: provides configuration parameters.

## Why This Structure?

Separating conceptual, procedural, and reference information
supports:

- Content reuse
- Consistent structure
- Easier maintenance
- Multiple publication outputs
- Topic-based navigation

## Skills Demonstrated

- DITA XML
- Structured authoring
- Topic-based writing
- Content reuse
- Information architecture
