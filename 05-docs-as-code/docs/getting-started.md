# Getting Started with Job Monitoring

## Overview

Job Monitoring provides administrators with a centralized view
of automated background jobs.

You can use Job Monitoring to:

- Review job status.
- Identify failed jobs.
- View processing details.
- Monitor retry attempts.

## Prerequisites

Before using Job Monitoring:

- You must have Administrator permissions.
- Automated job processing must be enabled.

## Access Job Monitoring

1. Sign in to NovaFlow.
2. Go to **Administration > Job Monitoring**.

The **Job Monitoring** page displays the available automated jobs.

## Job Status

A job can display one of the following example statuses:

- **Pending**: The job is waiting to be processed.
- **Running**: The job is currently being processed.
- **Completed**: The job completed successfully.
- **Failed**: The job did not complete successfully.
