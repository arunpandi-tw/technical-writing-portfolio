# Configure Job Monitoring

## Overview

Administrators can configure Job Monitoring to control monitoring
behavior for automated background jobs.

## Prerequisites

Before configuring Job Monitoring:

- Verify that automated processing is enabled.
- Ensure that you have Administrator permissions.

## Configure Job Monitoring

1. Go to **Administration > Job Monitoring**.
2. Select **Configuration**.
3. Enable **Job Monitoring**.
4. Specify the monitoring interval.
5. Configure notification settings, if required.
6. Select **Save**.

## Result

The system saves the configuration and applies the updated
monitoring settings.
